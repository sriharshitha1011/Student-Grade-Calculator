# Student Grade Calculator

A simple Python project that takes a student's name and marks as input, validates the marks, and calculates the grade using `if`, `elif`, and `else` conditional statements.

## Features

- Accepts student name and marks
- Validates marks between 0 and 100
- Calculates grades based on marks
- Displays the student's result clearly

## Technologies Used

- Python

## Concepts Practiced

- Variables
- User Input
- Data Types
- Type Conversion
- Comparison Operators
- `if-elif-else`
- Logical Operators
